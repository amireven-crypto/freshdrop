Accessibility Statement

Demo store: FreshDrop is a demo store – no real orders are processed. This statement describes the current state of the demo website and will be updated before a real launch.

Our goal

We want everyone to be able to use FreshDrop, including people who use screen readers, keyboards, magnification or other assistive technology. Our target is conformance with the Web Content Accessibility Guidelines (WCAG) 2.1, level AA.

Current status

We do not claim full conformance. The site has so far only been checked with automated tools (such as Lighthouse and automated contrast checks) and by our own manual keyboard and mobile testing. It has not yet been audited by an independent accessibility expert or tested with a full range of assistive technologies. Its status is therefore: not yet formally evaluated.

What we have done

  • A “Skip to main content” link and a consistent page structure with headings.
  • Text and interface colours chosen to meet the WCAG contrast ratios (4.5:1 for text, 3:1 for interface elements); a visible keyboard focus indicator.
  • Navigation and shop functions that work with the keyboard; buttons and menu controls have text labels and state information for screen readers.
  • Buttons and links sized for touch (at least 44 × 44 px where practical); the layout adapts to small screens and does not scroll sideways.
  • Decorative animation is switched off if your system is set to “reduce motion”.

Known limitations

  • Product pictures are currently AI-generated illustrations; their text alternative is only the product name, not a detailed description.
  • The decorative scrolling banner on the home page moves continuously and has no pause button (it is hidden from screen readers, pauses when you hover over it, and stops if you enable “reduce motion”).
  • The website needs JavaScript to display products.
  • The legal texts are templates in English only, contain unfilled placeholders and have not been reviewed by a lawyer; they are not available in German yet.
  • The checkout, payment and withdrawal functions are not implemented, so their accessibility has not been assessed.
